🎯 How to Test in Real Application

  1. Start a meeting as host
  2. Join as participant in another browser/tab
  3. End the meeting as host
  4. Check participant browser - should show "Meeting Ended" message and redirect to dashboard
  5. Check console logs - should see status change detection logs

🚨 Troubleshooting

If participants still don't get redirected:

  • Check browser console for error messages
  • Verify the meeting status is actually changing to 'ENDED' in the database
  • Check if the GraphQL query is polling correctly
  • Try refreshing the participant's browser page
