🔧 Backend Data to Check

1. Check User Creation in Backend

Run this query in your backend GraphQL playground:

Query:
query GetAllUsers {
  getMembers(input: { limit: 100, offset: 0 }) {
    total
    members {
      _id
      email
      displayName
      systemRole
      createdAt
    }
  }
}

2. Check Admin User Exists

Look for a user with systemRole: "ADMIN" in the response above.

3. Test Admin Login

Try logging in with admin credentials:

Mutation:
mutation AdminLogin($input: LoginInput!) {
  login(input: $input) {
    token
    user {
      _id
      email
      displayName
      systemRole
    }
  }
}

Variables:
{
  "input": {
    "email": "admin@example.com",
    "password": "admin123"
  }
}

4. Check Backend Schema

Verify that the backend supports the ADMIN role:

Check SystemRole enum in backend:
enum SystemRole {
  ADMIN
  TUTOR
  MEMBER
}
