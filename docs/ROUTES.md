# Routes (Pages Router)

- /login                  -> Login form (uses login)
- /signup                 -> Sign up form (uses signup)
- /                       -> Main dashboard w/ tabs (Started / Scheduled / Ended)
- /waiting                -> Invite-code entry (joinMeetingByCode)
- /meeting/[meetingId]    -> Live stream room (WebRTC/LiveKit + signaling)
- /attendance/[meetingId] -> Ended meeting detail (durations, participants)
- /vod                    -> VOD management (list/upload/url/edit/delete)
- /admin                  -> Admin dashboard (global stats, meetings)
